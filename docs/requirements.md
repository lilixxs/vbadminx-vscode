# VBA 语言服务扩展需求

状态：已确认的首版需求。当前已实现首版语言服务器、COM 类型索引与 AI 接入，验收范围与限制见 [实现说明](implementation.md)。
本文定义验收目标。不得用本需求表替代真实执行记录。
领域术语以 [GLOSSARY.md](../GLOSSARY.md) 为准。

## 1. 产品边界

| ID | 需求 |
|----|------|
| BND-01 | 本产品是 VS Code 扩展，为其他工具导出的 VBA 源文件提供语言服务。 |
| BND-02 | 首版支持标准模块、类模块、文档模块和窗体模块，对应导出文件 `.bas`、`.cls`、`.frm`。 |
| BND-03 | 源码工程的导入导出由其他工具负责，不属本扩展。 |
| BND-04 | COM 类型信息的导入导出属本扩展。此能力与 BND-03 的源码工程导入导出无关。 |
| BND-05 | 本扩展不连接 Office、不同步工程、不运行宏、不调试宏、不提供窗体设计。 |
| BND-06 | 基础语言服务在扩展主机内离线完成。无 Office、无 AI 时基础服务仍可用。 |
| BND-07 | AI 能力复用宿主已有 AI 通道。AI 不替代基础语言服务，也不进入无 AI 环境的验收前提。 |

## 2. 平台与运行环境

| ID | 需求 |
|----|------|
| PLT-01 | 目标平台为 Windows、macOS、Linux。 |
| PLT-02 | 目标环境含本地、Remote SSH、WSL、dev container。语言服务在扩展主机运行。 |
| PLT-03 | 在上述环境且无 Office、无 AI 的条件下，第 5 节源码级功能保持可用。依赖外部类型的功能按 COM-06 降级。 |

## 3. 工程识别与配置

| ID | 需求 |
|----|------|
| PRJ-01 | 一个导出目录对应一个 VBA 工程。 |
| PRJ-02 | 一个工作区可含多个工程。不同工程默认符号隔离。 |
| PRJ-03 | 工程发现优先读取工程配置文件 `vba-project.json`。 |
| PRJ-04 | 无配置文件时，仅当工作区根或其直接子目录呈现 `模块/`、`类模块/`、`表格对象/`、`窗体/` 四类中文目录布局时自动识别为工程。 |
| PRJ-05 | 不满足 PRJ-04 的文件按单文件语法模式处理，不归属任何工程。 |
| CFG-01 | 工程配置可声明：模块类型映射、模块名映射、宿主、外部引用、类型索引、条件编译常量、目标位数。 |
| CFG-02 | 模块名与模块类型判定优先级：显式配置 > 标准 VBE 头 > 目录约定 > 扩展名。 |
| CFG-03 | 无头、无配置的文件从文件名推导模块名。 |
| CFG-04 | 配置与 VBE 头冲突、或多个文件解析出重名模块时，扩展报告配置问题。 |
| CFG-05 | 存在 CFG-04 冲突的符号禁用重命名。 |
| PRJ-06 | 文件改名后，扩展仅提示需同步配置或头信息，不自动改写源文件或 VBE 头。 |
| CFG-06 | 配置文件 schema 留待实现设计。本文已规定的默认行为必须保留。 |

## 4. 输入与文件处理

| ID | 需求 |
|----|------|
| INP-01 | 输入含两类：纯代码导出文件、含标准 VBE 导出头的文件。两类均需支持。 |
| INP-02 | 仅支持 UTF-8，允许有 BOM 或无 BOM。保存时保留原 BOM 状态与换行形式，禁止静默转码。 |
| INP-03 | 非 UTF-8 文件提示用户在扩展外转换编码。转换前不做语义分析，不输出误导性诊断。 |
| SYN-01 | 语法目标为 VBA7 为主，兼容常见 VBA6 语法。 |
| SYN-02 | 必须支持：条件编译、`Declare`、`PtrSafe`、`LongPtr`、`Property`、`Implements`、`WithEvents`。 |
| SYN-03 | 不支持 VB6 工程与 VB.NET。 |
| SYN-04 | 识别并保留 `Attribute`、设计段与资源引用。默认原样保留；显式启用设计段格式化时仅允许调整不影响含义的排版。`.frx` 文件不解析、不改写。 |
| SYN-05 | 不承诺解析窗体控件设计信息。缺控件定义时按 COM-06 处理。 |

## 5. 语言功能与验收

本节列出全部首版语言功能及其验收条件。表中“确定”指语义可由源码或已加载类型索引证实；无法证实时按 LIM-01 处理。

### 5.1 高亮与诊断

| ID | 功能 | 验收输入 | 预期结果 |
|----|------|----------|----------|
| LSP-01 | 语法高亮 | 关键字、标识符、字符串、注释、数字混排的 VBA7 源文件 | 各词法类别按语法着色；注释与字符串内容不被着色规则破坏 |
| LSP-02 | 语义高亮 | 同工程内可解析的符号引用 | 同名符号与局部变量按语义区分；无法解析的引用不赋予确定语义色 |
| LSP-03 | 语法诊断 | 缺 `End`、不配对结构等纯语法错误 | 报告语法诊断，位置指向错误起点 |
| LSP-04 | 语义诊断 | 可解析作用域内的类型不匹配、参数不符 | 报告诊断并给出依据；仅在证据确定时报告 |
| LIM-01 | 语义保守性 | 缺类型信息的成员访问、未知分支的条件编译 | 标记信息不足或提示缺配置，不得报“确定错误” |
| LIM-02 | 条件编译分析 | 配置了条件编译常量的工程 | 默认只分析生效分支；未定分支按 CFG-01 提供的常量判定；未配置时提示，诊断级别可配置，不改变 VBA 条件编译规则 |
| LIM-03 | 隐式变量 | 无 `Option Explicit` 的过程内未声明变量 | 不报确定性错误 |
| QF-01 | 快速修复：插入声明 | 确定作用域内未声明且首次赋值可判定的局部变量 | 提供插入 `Variant` 声明的修复，执行前预览；不自动删代码、不改错误处理、不加引用 |
| QF-02 | 快速修复：大小写修正 | 符号大小写与确定声明不一致 | 提供大小写修正修复，执行前预览 |

### 5.2 补全、悬停、导航

| ID | 功能 | 验收输入 | 预期结果 |
|----|------|----------|----------|
| LSP-05 | 符号补全 | 过程内输入标识符前缀 | 提供当前作用域可见符号；工程外符号来自类型索引 |
| LSP-06 | 成员补全 | `对象.` 触发 | 提供该对象类型可确定的成员；类型未知时不给确定成员列表 |
| LSP-07 | 悬停 | 悬停于过程名、变量、类型 | 显示签名与所属位置；外部符号显示类型索引中的说明 |
| LSP-08 | 签名提示 | 调用已知过程 | 显示参数序列与当前参数位置 |
| LSP-09 | 定义跳转 | 跳转至同工程或类型索引中的定义 | 同工程跳到定义处；外部符号给出来源库；多候选时列出候选 |
| LSP-10 | 引用查询 | 查询符号引用 | 返回工程内全部确定引用位置 |
| LSP-11 | 文档符号 | 查询当前文件符号 | 返回过程、属性、声明等结构 |
| LSP-12 | 工作区符号 | 按名查询工作区符号 | 返回各工程的匹配符号并标注所属工程；查询聚合不使工程共享符号解析作用域 |

### 5.3 重命名、格式化、折叠

| ID | 功能 | 验收输入 | 预期结果 |
|----|------|----------|----------|
| REN-01 | 确定引用重命名 | 工程内可解析的符号 | 声明与确定引用默认参与修改；执行前展示跨文件预览；同名普通文本不直接替换 |
| REN-02 | 推断候选 | 出现 `Application.Run`、`OnAction`、无法完全解析的成员调用 | 识别为推断候选，展示推断理由，默认不勾选；仅用户在预览中批准后才修改 |
| REN-03 | 源码外调用提示 | 被重命名符号为公共入口或事件过程 | 提示存在源码外调用可能 |
| REN-04 | 可撤销 | 任意重命名执行后 | 单次撤销可还原全部修改；冲突符号（CFG-05）禁用重命名 |
| FMT-01 | 缩进 | 文档格式化或选区格式化 | 默认 4 空格缩进，可配置 |
| FMT-02 | 关键字大小写 | 同上 | 按 VBA 关键字标准大小写规范，可配置关闭 |
| FMT-03 | 默认不做的格式化 | 同上 | 不自动折行、不重排声明、不格式化设计段；三项均可配置开启 |
| FMT-04 | 语义不变约束 | 应用任意格式化配置组合 | 不改变注释内容、字符串内容、条件编译语义与执行行为；该约束不可配置绕过 |
| LSP-13 | 代码折叠 | 长过程、多块文件 | 过程与代码块可折叠；设计段可折叠但内容保留 |

## 6. COM 类型信息

| ID | 需求 |
|----|------|
| COM-01 | 类型库提取只在 Windows 本机扩展主机运行，按该主机实际可用能力执行。 |
| COM-02 | 全平台支持保存、导入、导出可移植类型索引。索引记录格式版本、类型库 GUID、版本号、LCID 与位数。 |
| COM-03 | 工程必须显式选择所用类型库版本。禁止静默选用错误版本。 |
| COM-04 | 远程环境不自动桥接本机 Windows COM。提取在 Windows 侧完成后经 COM-02 索引交付。 |
| COM-05 | macOS、Linux 扩展主机读取类型索引，不做任何 COM 或 oleaut32 调用。 |
| COM-06 | 缺引用、缺窗体控件定义、缺宿主对象定义时，仍提供源码级分析；诊断标记信息不足，不报“成员确定不存在”；允许用户补充声明后参与分析。 |
| COM-07 | VBA 内建符号与库外部符号必须区分呈现。样例依赖 Excel、Office、ADODB、Scripting、MSXML2 五类库。 |
| COM-08 | 不承诺预装全部 Office 类型库。索引缺失时按 COM-06 处理。 |

## 7. AI 集成

| ID | 需求 |
|----|------|
| AI-01 | 通过 VS Code Language Model Tools API 公开只读项目上下文查询：符号、引用、诊断、用户选择的代码。 |
| AI-02 | 只读工具仅访问当前工作区，遵循宿主权限与信任流程。 |
| AI-03 | VBA 语言服务与只读工具不管理模型密钥，不自建聊天界面。开发验证用的可选模型适配器按 AI-06 处理。 |
| AI-04 | 不承诺兼容全部第三方 AI。验收经兼容的工具调用路径完成。 |
| AI-05 | 无 AI 时基础语言服务不受影响。AI 修改代码必须走宿主审阅流程，只读工具不得改源码。 |
| AI-06 | 开发原型可注册 OpenCode Go 聊天模型。默认复用本机 Magpie 代理中的 `opencode-go/deepseek-v4.1-flash`；官方直连使用独立 API Key，并仅保存在 SecretStorage 或扩展主机环境变量中。适配器不得读取 OpenCode 登录凭据，且不得成为基础语言服务的依赖。 |

参考（官方文档，仅用于 AI 集成实现设计）：

- VS Code AI 工具：https://code.visualstudio.com/api/extension-guides/ai/tools

## 9. 样例事实

只读参考目录（本机路径，仅作输入形态参考，不是构建依赖、不是可随意修改或发布的测试夹具）：
`D:\SVN_CQ24\trunk\doc\process\BAS(节能)\02-生成程序&生成结果备份\02-生成程序\X89-辅助小工具\vba_sync\X89-辅助小工具-V1_4.xlsm`

已实测事实：

- 该路径指向以工作簿文件名命名的目录。
- 目录包含 26 个 `.bas`、33 个 `.cls`、2 个 `.frm`，共 61 个文件。
- 其中 8 个 `.cls` 位于 `类模块/`，25 个 `.cls` 位于 `表格对象/`。
- 全部 61 个文件通过严格 UTF-8 解码，且均无 BOM。

边界说明：

- 该样例没有 `Attribute VB_Name` 头，也没有 `.frx` 文件。此事实仅限该样例，不得推广为产品结论。
- 不得以“样例无 `.frx`”推断窗体控件来源。
- 换行形式未经验证，本文不作断言。
- 样例代码引用窗体控件但无控件定义，按 COM-06 处理。
- 样例未覆盖的 VBA 语法按 SYN-01 至 SYN-03 判定支持范围。
